
# Odin Recipes

This is my first HTML project from The Odin Project.

The website contains three recipe pages: Lasagna, Pancakes, and Chicken Curry. Each page includes a picture of the dish, a short description, a list of ingredients, and the steps to prepare it.

## Skills I Practiced

- Creating HTML pages from scratch
- Using headings and paragraphs
- Adding images to a webpage
- Creating ordered and unordered lists
- Adding links between different pages
- Organizing files and folders
- Using Git and GitHub
